============================================================
STRUKTUR KONTEN WEB PEMBELAJARAN - BELAJAR NET (V2.0)
============================================================

1. DASHBOARD PENGGUNA (Gamified Hub)
   ├── Profil Dinamis: Nama Pengguna (Kakang/Kasyaf), Foto Profil, , Bio , Keamanan.
   ├── Statistik Utama:
   │   ├── XP (Experience Points) & Level Rank (Bronze to Grandmaster).
   │   ├── Streak Counter (Api Belajar): Menghitung hari beruntun.
   │   └── Heart/Life Bar: 5 Nyawa (Bisa di-refill dengan Coins atau tunggu 24 jam).
   ├── Progress Tree: Visualisasi jalur yang sedang diambil (Progress Bar %).
   ├── Achievements Gallery: Koleksi lencana (Badges) dari tantangan sulit.
   └── Global & Friend Leaderboard: Kompetisi skor mingguan antar user.

2. JALUR PEMBELAJARAN (Learning Paths Hierarchy)
   A. Python          : Python Basics, Algoritma, Scraping, Machine Learning.
   B. Next.js         : Server Components, App Router, API Routes, SSR & SSG.
   C. React           : State Management, Hooks, Context API, Axios/Fetch.
   D. Web Development : HTML5 Semantic, CSS Flexbox/Grid Semantic, Modern JavaScript, DOM Manipulation.
   E. Back-End        : RESTful API, PostgreSQL/MongoDB/MySql, Authentication, Token.
   F. Front-End       : Tailwind CSS, Framer Motion, Responsive Design.

3. STRUKTUR LEVEL DETAIL (Per-Jalur)
   ├── [LEVEL 1: EASY - THE BEGINNER]
   │   ├── Modul 1.1: Quiz Interaktif (Paham Input/Output & Konsep Dasar).
   │   ├── Modul 1.2: Tantangan Coding Kecil (Menyelesaikan 1-5 baris kode).
   │   ├── Modul 1.3: Proyek Mikro (Memasangkan logika sederhana menjadi fungsi).
   │   └── Checkpoint 1: "The Guardian Gate" (Ujian murni tanpa bantuan petunjuk).
   │
   ├── [LEVEL 2: NORMAL - THE BUILDER]
   │   ├── Modul 2.1: Deep Dive Quiz (Logika percabangan & perulangan kompleks).
   │   ├── Modul 2.2: Tantangan Coding Normal (Memperbaiki bug pada script).
   │   ├── Modul 2.3: Komposisi Fungsi (Membangun sistem modular kecil).
   │   └── Checkpoint 2: "Logic Mastery" (Tes ketahanan logika 15 menit).
   │
   ├── [LEVEL 3: HARD - THE ARCHITECT]
   │   ├── Modul 3.1: Quiz Arsitektur (Struktur data & optimasi performa).
   │   ├── Modul 3.2: Tantangan Coding Hard (Membangun fitur tanpa dokumen penuh).
   │   ├── Modul 3.3: Integrasi Kompleks (Menghubungkan antar modul/API eksternal).
   │   └── Checkpoint 3: "System Stress Test" (Membangun fitur dengan batas waktu).
   │
   ├── [LEVEL 4: EXPERT - THE SENTINEL]
   │   ├── Modul 4.1: Security & Optimization Quiz (Vulnerability & Clean Code).
   │   ├── Modul 4.2: Tantangan Coding Expert (Deployment & Scalability).
   │   ├── Modul 4.3: Proyek Skala Besar (Membangun aplikasi full-stack mini).
   │   └── FINAL CHECKPOINT: "Grandmaster Trial" (Review kode otomatis).
   │
   └── [FINAL PROJECT: CASE STUDY NYATA]
       └── Membangun aplikasi nyata yang siap dipublikasikan ke GitHub.

4. SISTEM REWARD & EKONOMI (Belajar Net Economy)
   ├── XP: Digunakan untuk naik level dan kustomisasi profil.
   ├── Belajar-Coins (Lingots):
   │   ├── Beli "Freeze Streak" (Agar streak tidak putus saat absen 1 hari).
   │   ├── Beli "Instant Level" (Skip level Easy/Normal dengan biaya besar).
   │   └── Beli "AI Logic Assistant Pass" (Akses bimbingan logika tak terbatas).
   └── Heart System:
       ├── Salah jawab = -1 Nyawa.
       ├── Nyawa habis = Tidak bisa lanjut belajar selama 12-24 jam.
       └── Practice Session: Selesaikan latihan lama untuk dapat +1 Nyawa.

5. TOOLS PENDUKUNG (The Developer Toolbox)
   ├── Integrated Playground: Code editor (Monaco base) di browser.
   ├── AI Logic Assistant (PREMIUM): 
   │   ├── Pembahasan mendalam: Menjelaskan teori di balik error.
   │   ├── Bantuan Logika: Memberikan arahan/pseudocode (Tanpa Jawaban Kode).
   │   └── Socratic Method: Menantang user dengan pertanyaan untuk memicu solusi.
   ├── Community Forum: Tempat bertanya per-level jika ada error sulit.
   ├── Cheat Sheet Center: Ringkasan rumus/sintaks yang bisa di-download.
   └── Debugging Mode: Fitur melihat letak error pada baris kode di Hard/Expert.

============================================================
DOKUMENTASI STRUKTUR: AI LOGIC ASSISTANT (FOR FIGMA DESIGN)
============================================================

1. KOMPONEN VISUAL (UI ELEMENTS)
   ├── Status Indicator:
   │   ├── Mode: "Thinking" (Animasi loading dots).
   │   ├── Mode: "Guidance" (Warna Biru - Memberikan logika).
   │   └── Mode: "Warning" (Warna Kuning - Deteksi celah keamanan).
   ├── Chat Bubble System:
   │   ├── User: Pertanyaan atau kode yang error.
   │   └── AI: Penjelasan berbasis teks (Markdown support untuk pseudocode).
   ├── Action Buttons:
   │   ├── "Minta Petunjuk" (Trigger logika selanjutnya).
   │   ├── "Jelaskan Error Ini" (Bedah baris kode yang salah).
   │   └── "Visualisasikan Alur" (Membuka mini-window flowchart).

2. LOGIKA PEMBAHASAN (CORE LOGIC)
   ├── Step-by-Step Hint: 
   │   - Tidak memberikan kode, tapi memberikan urutan algoritma (1, 2, 3).
   ├── Analogi Dunia Nyata: 
   │   - Menjelaskan konsep pemrograman sulit dengan perumpamaan sederhana.
   ├── Pseudocode Generator: 
   │   - Mengubah logika menjadi bahasa manusia yang terstruktur.
   └── Socratic Prompting: 
   │   - AI memancing jawaban dengan pertanyaan kritis ke pengguna.

3. FITUR "SECURITY CHECK" (SENTINEL MODE)
   ├── Analisis Kerentanan: Mendeteksi jika user menulis kode yang rawan (SQL Injection, XSS).
   └── Best Practice Suggestion: Menyarankan metode enkripsi atau validasi data yang lebih aman.

4. INTEGRASI PLAYGROUND
   ├── Line Highlighting: AI bisa menyorot baris kode tertentu yang logikanya kurang efisien.
   └── Comparison View: Menampilkan perbandingan logika lama vs logika yang lebih optimal (setelah tantangan selesai).
